# Portfolio Thomas

Portfolio responsive de Thomas, graphiste freelance spécialisé dans la création visuelle.

Ce projet a été réalisé à partir d'une maquette Figma dans le cadre d'un challenge d'intégration web.

## Fonctionnalités

- Navigation avec ancres
- Menu responsive pour mobile
- Présentation des articles récents
- Présentation des travaux en vedette
- Formulaire de contact
- Téléchargement du CV
- Liens vers les réseaux sociaux
- Design responsive pour ordinateur, tablette et mobile

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- Google Fonts

## Structure du projet

- `index.html` : structure principale du site
- `styles/style.css` : mise en forme et responsive
- `js/main.js` : fonctionnement du menu mobile
- `assets/` : images et ressources du site
- `README.md` : documentation du projet

## Vérification

Le code HTML et CSS a été vérifié avec les validateurs W3C.

- HTML : aucune erreur
- CSS : aucune erreur

## Lancer le projet en local

1. Ouvrir le dossier du projet dans Visual Studio Code.
2. Ouvrir `index.html`.
3. Lancer le projet avec Live Server.
